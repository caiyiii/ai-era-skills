# Phase 15.6 — Episode Production E2E & Scene Foundation

你现在继续开发 AI-Drama-Studio。

这是一个非常重要的“流程打通与产品可用性修复阶段”。

当前项目已经完成：

- Phase 13 — Episode Timeline / Composition Preview
- Phase 14 — Render Engine
- Phase 15 — Episode Production Workspace
- Phase 15.5 — Episode Production UX & Routing Unification

但是经过真实用户操作发现：

1. Season → Episode → “进入制作”点击后无法进入 Episode Workspace。
2. Episode Production 的真实浏览器流程尚未完整验证。
3. 用户目前无法可靠地从一集开始：
   Episode Plan → Script → Storyboard → Visual Assets → Audio Assets → Timeline → Render。
4. “剧集规划 / 剧本 / 分镜 / 时间线 / 成片”虽然已经有页面和路由，但实际生产链是否真正串起来尚未完成真实 E2E 验收。
5. 创作基础中的“场景 / Locations”目前仍然是占位页面：

   Locations

   # 场景

   管理故事发生的地点与空间氛围。

   当前项目步骤：世界观待开发步骤

   即将开始开发。本阶段不实现该步骤的真实业务。

   这说明 Location/Scene Foundation 还没有真正实现。
6. 当前产品已经进入“需要真正生产第一集”的阶段，不能继续只增加孤立页面或 Engine。
7. 本阶段必须以“真实用户能够生产一集”为最终目标。
