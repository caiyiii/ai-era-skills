==================================================
第四阶段目标
==================================================

建立统一的 AI Generation Engine。

第一阶段只实现：

「AI 世界观生成」

不要实现人物、剧集、剧本、分镜、图片、视频、TTS。

不要修改 Monorepo 技术栈。

不要重建项目。

不要修改已有 World CRUD 逻辑。

==================================================
一、AI Provider 抽象层
==================================================

在 API 中创建 ai module。

建立统一 Provider 接口。

至少支持：

generateText()
generateStructured()

接口不要绑定具体厂商。

第一版实现 OpenAI-compatible Provider。

配置使用环境变量：

AI_PROVIDER=
AI_BASE_URL=
AI_API_KEY=
AI_MODEL=

API Key 只能存在 NestJS API 服务端。

Web / Mobile / Desktop 绝对不能直接调用 AI Provider。

不要把 API Key 暴露给前端。

==================================================
二、Generation Task
==================================================

使用现有 GenerationTask Prisma Model。

检查当前 schema。

如果现有字段不足以支持 AI Generation，可以进行最小必要修改。

不要破坏已有数据。

任务状态至少支持：

PENDING
RUNNING
SUCCEEDED
FAILED
CANCELLED

任务至少记录：

id
projectId
type
status
input
output
provider
model

createdAt
updatedAt

如果当前模型已经有对应字段，复用，不要重复创建。

==================================================
三、Generation API
==================================================

建立：

POST /projects/:projectId/generations/world

功能：

用户传入世界观创作提示词。

例如：

“两大星系发生碰撞，两大文明发生交融，一个走向修仙，一个走向赛博科技。”

API 创建 GenerationTask。

执行 AI Generation。

保存结果。

返回结构化结果。

第一版允许同步执行。

暂时不引入 Redis / BullMQ / Worker。

但是代码结构必须允许以后改成异步 Job。

==================================================
四、Structured Output
==================================================

AI 不允许只返回自然语言长文本。

必须返回结构化 JSON。

World Generation Result：

{
  world: {
    name,
    description,
    cosmicBackground,
    coreConflict
  },

  civilizations: [
    {
      name,
      type,
      description,
      philosophy,
      society,
      culture,
      technology
    }
  ],

  histories: [
    {
      title,
      description,
      order
    }
  ],

  factions: [
    {
      name,
      description,
      civilizationName
    }
  ],

  locations: [
    {
      name,
      description,
      civilizationName
    }
  ],

  powerSystems: [
    {
      name,
      description,
      rules,
      levels
    }
  ]
}

要求：

1. 服务端验证 JSON Schema
2. AI 返回非法 JSON 时不能写入数据库
3. AI 返回结构不符合 Schema 时不能写入数据库
4. 生成结果先保存到 GenerationTask.output
5. 不自动覆盖当前 World 数据

==================================================
五、AI Prompt
==================================================

建立专门的 World Generation Prompt。

AI 的任务不是写小说。

AI 的任务是：

根据用户创意建立一个可以用于 AI 漫剧生产的结构化世界观。

要求：

- 世界观内部逻辑一致
- 文明之间有明确差异
- 文明的发展路径要有因果关系
- 历史事件可以支撑后续剧集
- 势力可以支撑人物关系
- 地点可以用于后续分镜
- 能力体系必须有明确规则
- 不要出现互相矛盾的设定
- 为后续人物、剧本、分镜生成提供足够信息
