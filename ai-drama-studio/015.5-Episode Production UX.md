你现在继续开发 AI-Drama-Studio。

这是 Phase 15.5。

本阶段不是新增 AI Engine，不新增 Provider，不新增 Render Engine，不重做 Timeline，不重做 Script / Storyboard 数据模型。

本阶段的唯一核心目标：

==============================
Episode Production UX & Routing Unification
==============================

把当前项目从：

Project
├── Season
├── Episode List
├── Script
├── Storyboard
├── Timeline
├── Render
└── Asset Library

这种“项目级平行模块”结构，

统一调整为：

Project
├── World
├── Characters
├── Story Bible
├── Locations
│
└── Content Production
    ├── Season Planning
    └── Episode Workspace
         │
         ├── Episode Plan
         ├── Script
         ├── Storyboard
         ├── Visual Assets
         ├── Audio Assets
         ├── Timeline
         └── Render / Episode MP4

用户的核心工作对象必须始终是：

Episode

用户应该能够：

项目
→ Season
→ Episode
→ Episode Production Workspace
→ 按生产阶段逐步完成这一集
→ 最终 Render MP4

而不是：

项目
→ 剧本
→ 又回到 Episode List
→ 分镜
→ 又回到 Episode List
→ 时间线
→ 又回到 Episode List
→ 成片
→ 又回到 Episode List

================================
二、必须遵守的产品原则
================================

本阶段最重要的产品原则：

# Episode 是生产核心对象

所有“制作一集”的操作，都必须有明确 episodeId 上下文。

以下功能：

- Episode Plan
- Script
- Storyboard
- Visual Assets
- Audio Assets
- Timeline
- Render

全部属于某一个 Episode。

因此：

错误：

/projects/:projectId/script

正确方向：

/projects/:projectId/episodes/:episodeId/script

错误：

/projects/:projectId/storyboard

正确方向：

/projects/:projectId/episodes/:episodeId/storyboard

错误：

/projects/:projectId/timeline

正确方向：

/projects/:projectId/episodes/:episodeId/timeline

错误：

/projects/:projectId/render

正确方向：

/projects/:projectId/episodes/:episodeId/render

具体最终路径必须以当前项目已有路由为基础进行统一，不要凭空创建第二套路由。

如果现有项目已经存在：

/projects/:projectId/episodes/:episodeId

则必须以它为生产主入口。
