你现在正在开发一个名为 AI Drama Studio 的多端 AI 漫剧创作平台。

这是一个长期开发项目。

产品目标：

让用户可以创建自己的 AI 漫剧，并通过以下流程逐步完成：

Project
→ World
→ Characters
→ Locations
→ Episodes
→ Script
→ Storyboard
→ Images
→ Videos
→ Voices
→ Render

产品需要同时支持：

1. Web 浏览器
2. Android
3. iOS
4. Windows Desktop
5. macOS Desktop

必须从项目初始化阶段考虑多端架构。

==================================================
六、共享代码
==================================================

packages/types：

存放：

Project
Episode
Character
Location
Asset
GenerationTask

以及相关 enum。

packages/api-client：

创建统一 API Client。

Web / Mobile / Desktop 必须使用相同 API Client。

禁止三个客户端分别实现 API 请求。

packages/core：

存放跨平台业务逻辑。

例如：

- project logic
- generation task state
- workflow state

业务逻辑不要写死在 Nuxt 页面组件中。

packages/utils：

存放纯工具函数。

==================================================

Client
→ Backend
→ Storage

作为唯一方案。

Client
→ Presigned URL
→ Object Storage

- 创建上传任务
- 生成签名URL
